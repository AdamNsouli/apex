# Asset inventory — 0.3.0-beta.1

APEX's step mark is original vector geometry. It appears as the product mark, favicon and SVG symbol. Its route motif corresponds to real pair changes in history. No AI-generated raster buttons or runtime sprites are needed; nodes and interactions are vector/CSS/native primitives.

The Kavren mark is the owner-provided Archivo ExtraBold K outline with a separated leg. It is monochrome and restricted to publisher/setup/About contexts. The copied outline and Archivo license notice are bundled; this is the existing Kavren identity, not a newly invented logo. Product controls remain APEX.

## Local font provenance

All font sources and OFL notices were retrieved from the official [Google Fonts repository](https://github.com/google/fonts/tree/7085eb89a950e85db5b166b7a58d414544b4140c) at the pinned commit `7085eb89a950e85db5b166b7a58d414544b4140c`:

- Inter: `ofl/inter/Inter[opsz,wght].ttf` and `OFL.txt`.
- Space Grotesk: `ofl/spacegrotesk/SpaceGrotesk[wght].ttf` and `OFL.txt`.
- JetBrains Mono: `ofl/jetbrainsmono/JetBrainsMono[wght].ttf` and `OFL.txt`.
- Archivo publisher-outline notice: `ofl/archivo/OFL.txt`.

Files retain their SIL Open Font License notices byte-for-byte, including upstream line endings. Font assets are served from the local companion with `font-display: swap`; there is no font CDN or external runtime request. Original SVG code follows the repository MIT license; font software and derived glyph notice retain their own license.

The legacy `mode-glyphs.svg` and original design pack remain design history. They do not define current mode colors, buttons or runtime behavior.
