# Product and UI contract

The HTML in `visuals/Apex_UI_Prototype.html` is the visual authority for the populated desktop screen. The text here governs behavior; synthetic example states are not production telemetry. Keep the calm, dense instrument aesthetic. No mascot, trophy, flame animation, gradients, particle backgrounds, fake success rates or fake progress percentages.

## Tokens and layout

Dark tokens: background `#0B 0C 10`, panel `#12141A`, nested panel `#191C 24`, border `#232733`, hover border `#303645`, primary text `#E 9EBF 1`, secondary `#9BA 3B 5`, muted `#858EA 1`, accent `#5B 8CFF`, success `#3ECF 8E`, warning `#E 8A 33D`, danger `#E 5544B`. Eco green, Balanced blue, High Quality ivory, Sports amber. Never encode status in color alone. Light theme: background `#F 4F 5F 8`, panel white, nested `#ECEFF 5`, border `#D 6DCE 7`, primary `#151923`, secondary `#49556A`; preserve mode colors with contrast-tested darker text equivalents.

Typography: locally bundled Inter for UI, Space Grotesk for product/display and JetBrains Mono for numbers; provide system fallbacks. Verify font licenses and include them if downloaded. No runtime font CDN. Sizes: product 22/600, page 24/600, section 16/600, body 14/400, metadata 12/400, metric 26/600. Labels never smaller than 12. Spacing multiples of 4. Outer desktop pad 32, vertical gaps 20, cards pad 20, card radius 10, buttons 8, dialog 12, all 1px borders. Minimum hit target 40x 40, keyboard focus 2px blue with 2px offset, content WCAG AA.

Desktop reference 1440x 1000: 64px top bar, content max 1376 centered; left workspace 208px, gap 24px, remaining main area. Sidebar contains Overview, Timeline, Models, Settings and connection status. Main heading “Routing console”, one sentence “Every request. The right model. A visible receipt.” Right actions Auto [active/manual] and Allow credits. Mode strip four equal cards, each with vector glyph, title and one-line description. Selected has accent border and inset left 3px marker. It is a radio group, not four independent toggles. Controls stay available while streaming.

Below mode strip: truthful pending/current status band; four metrics (active request, observed cost, estimate for next request, data freshness). Metric subtitles expose scope and provenance. Below: two-column grid 65/35, timeline on left, decision card on right. Timeline is the primary surface: ordered request/tool events, time, sequence, agent/main identifier, safe task label, requested model and effort, response model badge if known, status. Timeline steps expand inline into decision and cost receipt. The small chart is secondary and has an accessible text/table alternative. No percentage completion unless a true known work count exists; elapsed time/requests/tool statuses are sufficient.

The right card shows candidate pairs, AA quality evidence for selected task, projected cost range, expected latency if measured, excluded reasons and why the selection won. “Evidence, not a success probability” appears below normalized utility. Footer attribution “Benchmark data: Artificial Analysis · methodology [version] · fetched [timestamp]”. Open drawer exposes original benchmark names/raw scores, model variant, price source, calculation and missing fields. Fields absent from the tier show “Not provided by connected tier”.

## Control semantics and copy

- Mode buttons: Eco “Lower cost within a quality floor”; Balanced “Quality, speed and cost”; High Quality “Strongest task evidence”; Sports “Near-best quality. Faster delivery.” Eco leaf/path, Balanced split-path, Quality converge, Sports zigzag. Use supplied precise vector assets for controls. Decorative generated atlas is optional on onboarding/about only.
- On click, send `{id,expectedRevision,kind:'set_mode',mode}`. Optimistic highlight has “Saving…”; only server ACK commits. If a request is active: “Sports queued · applies to request #N+1”. Once consumed: “Sports active · revision R”. Inflight row stays unchanged. Rapid changes last acknowledged revision wins; conflicts refetch, no silent reversion.
- Auto shows current routing state; click toggles Auto or Manual hold. A native `/model` or `/effort` selection enters Manual hold only where detected by supported host signals. If detection cannot be guaranteed, automatic routing requires a clearly labelled explicit opt-in in onboarding and a manual hold button; never claim override protection without verified detection. A pinned model/effort from environment/config is always preserved unless user explicitly chooses to unpin.
- “Allow credits” opens a dialog. Heading “Permit credit-funded routing”; fields “Session API-equivalent budget (USD)” and explanatory account state. Default 0, positive value required. Actions “Open Claude billing”, “Cancel”, “Allow within budget”. Native billing command is queued until idle; label shows “Billing will open when this turn ends”. Mod consent can be toggled mid-run; billing/account state remains separately unknown/verified. If no supported billing command, show copyable `/usage-credits` with “Run in Claude Code”. Do not invent a URL or secretly submit an administrator request. Browser/host commands must remain user initiated.
- Credits status uses states “Not allowed by APEX”, “Allowed by APEX · account unverified”, “Allowed · account reports enabled”, “Budget reached”, “Billing unavailable”. Account state must come from documented evidence; never infer it from button click, API-equivalent cost or rate-limit absence. No auto credit purchase. Revoke applies next unsent request; committed request cost cannot be undone.
- Native pane commands `/apex`, `/apex mode eco|balanced|quality|sports`, `/apex auto`, `/apex hold`, `/apex why`, `/apex models`, `/apex credits`, `/apex doctor`. Register controls requiring mid-turn operation as immediate if the installed API supports it. Unsupported immediate capabilities must be disclosed.
- User task override in details: General / Coding / Agentic coding / Math / Engineering / Finance / Strategy / Legal / Healthcare / Economics. Persist for current intent only. High-risk checkbox can add caution; user cannot remove host permissions or redefine real high-risk triggers.

## Native pane

Minimum 72 columns,18 rows. Header `APEX | Connected | Auto`; mode radios one row; next line `Main: [requested model] · [requested effort] · [streaming/idle]`; pending revision line only when needed. Compact metric line labels `Observed API≈`, `Next estimate≈`, `AA age`, `Credits`. Last six chronological events plus detail/open-dashboard buttons. At 48 columns modes wrap 2x 2, metrics vertical, model IDs truncate visually but full ID in details. Do not shrink text or rely on terminal raster image support. Use host `Box/Text/Button/Select` through `$.ui.resolve(e)`, ASCII fallback glyphs `[E] [B] [Q] [S]`, no unsupported DOM elements. Browser is optional; controls and routing work if it is closed or companion cannot start.

## Browser navigation and states

Overview displays summary plus latest timeline. Timeline displays all retained events, filter All/Main/Agents/Tools/Errors and searches safe labels/IDs. Models displays available/routable/excluded table, effort variants, raw benchmarks, freshness, capabilities and source links; no score invented for unmatched models. Settings displays data connection, refresh, permissions, theme, retention, caps, disable-router control. Export downloads a sanitized receipt JSON for the currently selected session after explicit click; no transcript/keys/thinking included. Inspect opens the matching real decision drawer.

Empty: “No requests yet” and “Routing begins with your next Claude request.” Loading: skeleton/“Connecting to local session…” for 2s then retry; no invented zeros. AA missing key: “Connect Artificial Analysis to enable benchmark routing” with credential setup. Routing stays on native model/effort until connected valid evidence and compatible alternatives exist; pane/telemetry still operate. Error: cause/time/retry without tokens. Stale 24h: amber badge;72h disables automatic model downgrades;7days disables automatic model switches until refreshed, retains safe supported native settings. Unsupported host: routing disabled with exact missing capability and verified upgrade requirements. Disconnected: visible badge, controls disabled with explanation, last-known facts stamped with timestamp. Budget reached: block mod-created paid upgrade, native baseline only if charge status permits; strict charged mode pauses boundary on uncertainty.

At <1100px sidebar collapses to 64px labels appear on focus; at <900px sidebar becomes top tabs, main cards single column and timeline above decision; at <600px padding 16, mode cards 2x 2, metrics 2x 2, table becomes labelled stacked cards and details full-screen dialog. Reference mobile 390x 844. At 200% zoom controls wrap, no horizontal scroll except explicitly scrollable model table.

Accessibility: semantic landmarks, radio keyboard arrows, label/description for every input, live polite mode ACK, dialog focus trap/Escape/restoration, timeline selected focus retained during incoming events, no auto-scroll away from user selection. Reduced motion disables signal pulses. Default vector status sprite update at 1Hz only while active, freeze when hidden; static label always present. New events don't move buttons. Screen reader alternative lists request/model/effort/status/cost/source in ordinary text.
