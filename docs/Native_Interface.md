# Native interface — 0.3.0-beta.1

APEX uses Claude Code's [public native UI hooks](https://code.claude.com/docs/en/plugins/mods/interface). It needs no terminal patch, browser or companion for its native controls. Supported primitives and pane contracts were checked against the SDK generated by Claude Code 2.1.292.

| Surface              | Contract                                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Terminal AbovePrompt | Expanded two-row strip, one-row compact preference or hidden; preserves downstream UI and yields to surveys       |
| Terminal Pane        | Compact rail at requested 34 body columns; host determines actual width, docking, full height and inline fallback |
| Desktop Pane         | Same supported primitives and callbacks; harness verified, actual desktop rendering unverified                    |
| Browser              | Optional broader history, catalogue setup and exports; never required to route                                    |

`/apex` or `/apex rail` opens compact view without forcing keyboard focus away from the composer. On full-screen terminals Claude can dock from 110 columns; APEX never promises a floating short-height overlay. The real 144-column capture docked with a 34-column body. At 80 columns it opened inline. A docked rail suppresses APEX's prompt strip; inline layout can retain the strip. Native layout/scrolling remain host-owned.

The rail prioritizes its current pair and Mode/Inspect controls before recent requests. Narrow inline windows may scroll. Selecting a request opens one inspector containing paginated history, verdict, native/outgoing/response settings, decision reason, frozen evidence, forecasts and observed costs. The selected ID persists while new events arrive. Follow live resets selection to the active/latest event. Agent view shows its observed native pair and does not claim automatic agent routing.

Settings provides host information, evidence freshness and refresh eligibility, secure AA connection instructions, discovered IDs, explicit access confirmation, exact variant/effort selection, task evidence, display preference and publisher identity. An incompatible exact effort cannot be confirmed through the guided chooser; advanced mappings are accepted as user assertions but still quarantined by catalogue checks. Keys never appear in a native plain text input. Credit consent has its own positive finite budget form and explicit revoke action; it does not activate account billing.

Focus the strip through Claude's `ctrl+x tab` or a click. `m` opens its mode chooser and `i` opens the rail. The chooser uses `e/b/q/s`. No digits or global composer shortcuts are registered. Tab/Enter, Escape and pane scrolling are host-owned. Native Button has no disabled property in this SDK: unavailable controls render as dim noninteractive text, and action handlers still validate eligibility.

Mode acknowledgments mean **saved to the host**, not applied to an existing provider invocation. A separate mode revision is consumed only by a main dispatch; mapping/consent revisions cannot masquerade as queued mode changes. Quality once is claimed synchronously before forwarding, cannot be consumed by agents, preserves the base mode and cannot bypass any guard. A guard-retained main request consumes it and records that attempt. Restart/clear cancels it.

Native fonts/colors/button chrome belong to Claude. There are no injected web fonts, scripts or SVG action handlers in the terminal. AbovePrompt remains capability-specific to the supported terminal render site.

## Screenshot provenance

`native-terminal-*.png` reproduces **genuine host PTY output** using an ANSI parser and local JetBrains Mono rasterization. It is not an OS screenshot, and font glyph coverage differs from the person's terminal. The CLI used isolated temporary configuration, a dummy credential and an unreachable loopback inference URL. Only local slash commands were entered. No live inference or real AA evidence was used.

`native-interface-reference.png` renders the shipped primitive tree with synthetic events; it is a reference, not host paint. Browser pictures come from the shipped app and real local transport, backed by explicitly labeled synthetic state. No screenshot claims measured benchmark results, provider acceptance or billing.
